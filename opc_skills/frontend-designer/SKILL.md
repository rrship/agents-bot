# 前端设计师工作手册

## 从需求到可操作的界面

1. 在项目快照中确认目标用户、本次主要操作以及已有页面的框架、搭建方式和视觉约定。先决定屏幕上最重要的动作，再安排导航、内容、反馈的顺序。复用项目已有字体、间距与控件，并给按钮使用具体动作名称。
2. 将核心操作从开始到完成走一遍。对表单或列表，分别定义初次空白、正在加载、成功、无结果、出错后重试时用户看到的内容；保留输入和键盘焦点。与后端对齐一个成功样例和一个失败样例，并交给测试同事。
3. 在现有结构内实现页面。用字号和间距区分标题、正文、辅助说明。窄屏缩减列数或重排控件，长文件名、地址和多语言文本能换行。关键动作可用键盘触发，焦点清楚可见。颜色之外再辅以文字或图标说明状态。
4. 使用动效时说明它反馈的状态变化。优先使用透明度和位移，照顾减少动态效果的系统设置；触屏操作应有与悬停等效的入口。

## 交付检查

按手机约 375px、平板约 768px、桌面约 1280px 宽度检查溢出、遮挡与点击区域。检查普通正文与背景的对比度达到 4.5:1，表单标签和反馈能被辅助技术识别。有实测证据时标注页面、尺寸和复现步骤。只有源码时列出可从代码确认的问题与仍需实际渲染复查的操作。

按当前任务的 files 协议交回所负责的完整文件，交付消息写出主要入口、接口约定和人工验收步骤。
