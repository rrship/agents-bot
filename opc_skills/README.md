# OPC 岗位技能与出处

每个岗位目录中的 `SKILL.md` 是随包提供的中文改编版。工作台将正文随本轮任务交给员工绑定的模型或本地软件。同一套手册可以跨模型使用，已有项目文件、实际分工和本轮输出格式由工作台另外提供。读取手册无需联网。

| 员工 | 随包手册 | 采用的上游方法与本地改编 |
| --- | --- | --- |
| 项目经理 | [SKILL.md](project-manager/SKILL.md) | 将独立可验收的交付切片和依赖关系转换成本地岗位派单，并从集成结果复核交付。[to-tickets](https://github.com/mattpocock/skills/blob/abeeaf95660ba9e8b7c753eb38f441ca707a8823/skills/engineering/to-tickets/SKILL.md) |
| 前端设计师 | [SKILL.md](frontend-designer/SKILL.md) | 从界面实现和设计审查技能中选择视觉层级、动效、响应式与键盘操作方法，补充数据状态与 API 对接方式。工作台只提供源码时，手册会要求列出待实机复查项。[premium-frontend-ui，作者 Utkarsh Patrikar](https://github.com/github/awesome-copilot/blob/f10fdb8b2660ce85c98f220b2f1ca24653768a5c/skills/premium-frontend-ui/SKILL.md) · [web-design-reviewer](https://github.com/github/awesome-copilot/blob/f10fdb8b2660ce85c98f220b2f1ca24653768a5c/skills/web-design-reviewer/SKILL.md) · [视觉检查表](https://github.com/github/awesome-copilot/blob/f10fdb8b2660ce85c98f220b2f1ca24653768a5c/skills/web-design-reviewer/references/visual-checklist.md) |
| 后端开发员 | [SKILL.md](backend-developer/SKILL.md) | 采用小接口、调用者视角、依赖边界和可替换适配器的设计方法，补充本地多成员的接口交付与失败恢复约定。[codebase-design](https://github.com/mattpocock/skills/blob/abeeaf95660ba9e8b7c753eb38f441ca707a8823/skills/engineering/codebase-design/SKILL.md) · [依赖与边界](https://github.com/mattpocock/skills/blob/abeeaf95660ba9e8b7c753eb38f441ca707a8823/skills/engineering/codebase-design/DEEPENING.md) |
| 测试工程师 | [SKILL.md](qa-engineer/SKILL.md) | 基于公共接口的测试驱动循环、独立期望值与可观察行为，分别交付可运行用例和实际运行凭据。[tdd](https://github.com/mattpocock/skills/blob/abeeaf95660ba9e8b7c753eb38f441ca707a8823/skills/engineering/tdd/SKILL.md) · [测试示例](https://github.com/mattpocock/skills/blob/abeeaf95660ba9e8b7c753eb38f441ca707a8823/skills/engineering/tdd/tests.md) |
